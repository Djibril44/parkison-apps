⚡ 5 ÉTAPES POUR DÉPLOYER:

ÉTAPE 1: Créer GitHub Repository
─────────────────────────────────

1. Allez sur: https://github.com/new
2. Nom: parkinson-app
3. Public (pour plan gratuit)

Puis en terminal:
$ git init
$ git add .
$ git commit -m "Initial commit"
$ git branch -M main
$ git remote add origin https://github.com/VOTRE-USERNAME/parkinson-app.git
$ git push -u origin main

ÉTAPE 2: Connecter à Render
───────────────────────────

1. Allez sur: https://render.com
2. Sign Up avec GitHub
3. Connect GitHub Account
4. Cliquez "New" → "Web Service"
5. Sélectionnez le repository parkinson-app
6. Cliquez "Connect"

❌ TROUBLESHOOTING:

Erreur: "Exited with status 1"
└─ Vérifiez que Procfile existe
└─ Vérifiez DATABASE_URL est défini
└─ Cliquez "Manual Deploy"

Erreur: "relation user does not exist"
└─ Exécutez python setup.py
└─ Les tables ne sont pas créées

Erreur: "502 Bad Gateway"
└─ Attendez 2-3 minutes
└─ Rechargez la page

Erreur: "Cannot connect to database"
└─ Vérifiez DATABASE_URL
└─ Testez: python test_connection.py
