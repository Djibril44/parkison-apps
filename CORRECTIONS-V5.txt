📋 PREMIER UTILISATEUR (ADMIN):

Pour créer le PREMIER admin:

Option 1: Via Python (local)
$ python
>>> from app import app, db, User
>>> with app.app_context():
...     admin = User(nom='Admin', email='admin@hospital.com', role='admin')
...     admin.set_password('votre-mot-de-passe')
...     db.session.add(admin)
...     db.session.commit()
...     print("Admin créé!")

Option 2: Directement sur production
Via la console/terminal:

python
>>> from app import app, db, User
>>> with app.app_context():
...     admin = User(nom='Administrator', email='admin@yourhost.com', role='admin')
...     admin.set_password('strong-password-here')
...     db.session.add(admin)
...     db.session.commit()

Une fois l'admin créé:
1. Il se connecte avec son email/password
2. Il va sur /admin/users
3. Il crée les autres utilisateurs
