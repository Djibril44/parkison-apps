✨ ÉTAPE 2: CONFIGURER RENDER

   New → Web Service

4. Sélectionnez votre repository:
   Cherchez "parkinson-app"
   Cliquez "Connect"

5. Configurez le service:

   Name: parkinson-app
   Environment: Python 3
   Region: Frankfurt (ou plus proche)
   Branch: main
   
   Build Command:
   ✗ Laissez vide (Render utilise Procfile)
   
   Start Command:
   ✓ gunicorn app:app

6. Cliquez "Advanced":
   Auto-Deploy: ✓ Yes (redéployer à chaque push)

❌ TROUBLESHOOTING:

Erreur: "Exited with status 1"
└─ Vérifiez Procfile existe
└─ Vérifiez DATABASE_URL est défini
└─ Consultez les logs Render

Erreur: "relation user does not exist"
└─ Exécutez python setup.py en local
└─ Ou utilisez Neon Console pour créer les tables

Erreur: "Cannot connect to database"
└─ Vérifiez DATABASE_URL est correct
└─ Vérifiez la connection string Neon
└─ Testez: python test_connection.py

Erreur: "502 Bad Gateway"
└─ Attendez 1-2 minutes
└─ Rechargez la page
└─ Vérifiez les logs
